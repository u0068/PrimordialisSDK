# More Cells
Adds more cells to the game.

## Features
- Cartilage cell (old hard cell)
- Aero-gel cell
    - Very light, brittle and insulating
- Damage detector
- Wall detector
- Ang vel meter
- Piezo cell
    - Make voltage proportional to stretch
- Fat cell
    - Big, soft, stores a lot of biomass
- Pin cell
    - Practically Immovable
- Toggle cell
    - Better than power switch
- Ability trigger variants
    - Inverted triggers
    - Negative triggers
- Seeker variants
    - Hider
    - Powered seeker

## Installation
Install with your mod manager
