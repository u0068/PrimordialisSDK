# Nucleus
The mod loader and runtime API for Primordialis!
Required by all Primordialis mods.

## Features
- Loads mod dlls into Primordialis
- Allows mods to resolve game functions and globals
- Allows mods to hook game functions
- Facilitates communication between mods

## Installation
Install with your mod manager

## Configuration
None

## Compatibility
Every mod depends on Nucleus
