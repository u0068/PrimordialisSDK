# ImGuiAPI
Lets mods use Dear ImGui in game.

## Features
- ImGuiAPI module

## Installation
Install with your mod manager

## Configuration
None

## Compatibility
Every mod that uses ImGui depends on this.\
Mods must use ImGui v1.93.0 to be compatible, acquire it from the SDK repo.\
If for any reason you need a different version of ImGui, contact the SDK devs.
