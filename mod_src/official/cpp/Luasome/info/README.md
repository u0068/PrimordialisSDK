# Luasome
Lua modloader for Primordialis

## Features
- Runs Lua mods
- Lets mods access the game's Lua API
- Allows adding creatures with Lua brains
- Allows adding Lua console commands

## Installation
Install with your mod manager

## Configuration
None

## Compatibility
All Lua mods depend on this mod.
