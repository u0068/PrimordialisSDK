# Simple template mod
This example mod explains the very basics of adding a creature to the game, or overriding an existing creature.
Adds a smiling face to the safe zone, and replaces the snail creature with a frowning face.
Also adds jellyfish to the gyre zone, using the body, brain and spawn function from the vanilla game.

## Settings
- `spawn_rate: number = 0.05` how frequently to spawn the smiles
- `useless: boolean = false` does nothing
